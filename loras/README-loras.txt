Put PixArt LoRA files in this folder (.safetensors only, in the
diffusers/PEFT format -- keys like transformer_blocks.0.attn1...).
They appear in the LoRA dropdown in the app -- use the Refresh list
button after adding one. Only LoRAs trained on PixArt (PixArt-Sigma)
fit this model; SD 1.5, SDXL and SD 3.5 LoRAs do not work here.
